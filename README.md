# SNaP Lab Tools

This repository includes a bunch of common analysis functions and tools used by the SNaP Lab

## Installation

This repo is not setup with `pip install`. Instead, just clone the repo and add the repo to your project's path.

## Dependencies

To use these functions, you will need the following packages installed in your python environment:
1. numpy
2. scipy
3. scikit learn
5. statsmodels
6. pandas
7. nibabel
8. tqdm
9. wget
10. GitPython

If you find missing dependencies, let me know! or edit this readme and submit a pull request.
