# Tutorials

Longer worked examples for each major component of the package — spatial null models, GAM fitting
and change-point detection, correlation statistics, network topology, cross-validated prediction,
and figure building.

:::{note}
These are being rewritten and are not published yet. In the meantime, the
[API reference](../api/index.md) documents every function with its parameters and usage notes.
:::

## What they will cover

Each tutorial will run on synthetic data generated over the real Schaefer parcellation geometry
bundled with the package, so anyone can execute them without access to a particular dataset. They
will be executed when the documentation is built, which is what keeps them from drifting out of
agreement with the code.
