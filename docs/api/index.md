# API reference

Every public function and class in `snaplab_tools`, grouped by what it is for. Each module
page opens with a short orientation; follow a name through for the full signature,
parameters, and notes.

For worked examples rather than signatures, see the [tutorials](../tutorials/index.md).

## Modules at a glance

| Module | What it covers |
| --- | --- |
| [Statistics](stats.md) | Correlation statistics, partial correlations, and tests on brain-map relationships. |
| [Null models](nulls.md) | Spatial null models for parcellated cortical maps. |
| [GAMs and change points](gams.md) | Generic GAM fitting, derivative signals, change-point detection, and a bootstrap engine. |
| [Network topology](topology.md) | Topology analysis functions for network neuroscience. |
| [Prediction](prediction.md) | Cross-validated regression with nuisance control, PCA, and permutation testing. |
| [Plotting](plotting.md) | Publication-figure helpers. |
| [Time series](timeseries.md) | Signal-processing utilities. |
| [Example datasets](datasets.md) | Synthetic data on real cortical geometry, for tutorials, examples, and tests. |
| [Brain maps](brainmaps.md) | Loaders for published cortical maps, resampled to a common parcellation. |
| [Utilities](utils.md) | Parcellation fetching, parcel-wise averaging, and small numerics. |
